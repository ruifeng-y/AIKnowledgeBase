# V0.5-C-ADR-001 — Semantic Gold and Real Evaluation

## Context

V0.4-N provided Mock-based contract evaluation and metrics. Semantic quality was unproven because Semantic Gold had 0 human-curated cases. V0.5-C adds trustworthy gold tooling and real evaluation infrastructure without fabricating ground truth.

## Decision

1. **Human Gold principle** — machine output is always `DRAFT` + `machine_generated`; only human review yields `GOLD`. Synthetic-as-GOLD is a hard validation error.
2. **Dataset version + contentHash** — gold datasets are versioned and hash-bound; published versions are immutable.
3. **Corpus snapshot** — benchmarks bind `corpusVersion` + `corpusHash`; production corpus is never silently used as live data.
4. **Real provider requirement** — semantic quality runs use real Embedding/Reranker/LLM via existing Provider Registry. No Mock fallback for quality claims.
5. **Provider failure isolation** — 429/timeout/auth become `PROVIDER_FAILURE`, not quality zeros; denominators are always explicit.
6. **Citation ≠ Groundedness** — separate metrics; groundedness judges never see gold labels.
7. **No composite score / no winner** — reports list individual metrics only.
8. **Evaluation is read-only** — no production schema/data mutation; fixtures and snapshots only.
9. **Reproducibility** — reports carry git, dataset, corpus, provider, config, evaluator fingerprints.

## Consequences

- Semantic quality cannot be claimed until `humanCuratedGoldCount >= 50`.
- Candidate generation accelerates authoring but cannot replace curation.
- Real benchmark cost is controlled and opt-in when credentials exist.

## Readiness sub-stage (Gold Curation & Provider Readiness)

1. **Human Gold gate** — `humanCurated >= 50` + 12 required categories + integrity. DRAFT/machine never counts.
2. **Machine-assisted rule** — `machine_assisted` only counts after human review; `machine_generated` never auto-promotes to GOLD.
3. **Category semantics** — multi-label `category[]` + `primaryCategory`; reports distinguish `caseCount` vs `categoryAssignmentCount`. Contract names (`numeric`/`identifier`/`date`) with legacy aliases normalized.
4. **Provider readiness** — independent of Gold; requires real config + Health + Smoke for Embedding/Reranker/LLM. Mock is never real-ready.
5. **Dual gate** — `REAL_BENCHMARK_READY = GOLD_READY && REAL_PROVIDER_READY`. Readiness ≠ Semantic Quality.
